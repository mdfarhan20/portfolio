# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Recruiters, hiring managers, and freelance clients evaluating Mohamed Farhan for web development roles or project work. Both audiences arrive with the same question — "is this developer good enough to hire?" — but weigh evidence differently: recruiters scan for technical breadth and project quality; freelance clients look for relevant domain work and communication clarity.

## Product Purpose

A personal portfolio that earns contact. The site's job is to leave a strong impression of skill and craft through showcased projects and technical breadth, then drive the visitor to reach out via LinkedIn, GitHub, email, or other listed channels.

## Positioning

A full-stack developer (React/Node/Express/Next.js) with a Computer Science foundation and a portfolio of six shipped projects spanning real-time apps, data visualization, form tools, and games. The differentiator is the breadth of project types combined with hands-on full-stack execution — not a single niche, but demonstrated ability to build across categories.

## Operating Context

Visitors arrive from job applications, LinkedIn profile links, GitHub profile, or direct sharing. The site is deployed to GitHub Pages at `mdfarhan20.github.io/portfolio/`. Evaluation is quick — a recruiter may spend 30-60 seconds scanning before deciding to dig deeper or leave.

## Capabilities and Constraints

- Single-page scroll site with five sections: Home, About, Projects, Skills, Contact
- Six featured projects with live demos and source code links
- 12 listed technical skills with proficiency levels
- Five contact channels: LinkedIn, GitHub, LeetCode, HackerRank, Email
- Framer Motion animations on scroll and hover
- Responsive: mobile and desktop breakpoints (Tailwind)
- Static deployment (GitHub Pages) — no server-side logic
- No blog, no CMS, no dynamic content — all data hardcoded in `src/constants.ts`

## Evidence on Hand

- Six live project links with corresponding GitHub repos (Inquire, Confab, Spyfall, SortViz, Wordle, Music Player)
- Desktop and mobile hero photographs (`photo-desktop.png`, `photo-mobile.jpeg`)
- About section photograph (`about-photo.jpg`)
- Project screenshot images for all six projects
- Contact links with verified URLs

Absences that future work must not fabricate: no testimonials, no client logos, no case studies, no metrics (traffic, users, stars), no blog posts or writing samples.

## Product Principles

1. **Earn contact, not clicks.** Every element should move the visitor closer to reaching out, not just scrolling through.
2. **Projects are the proof.** Live demos and source code are the primary evidence of capability — more persuasive than any self-description.
3. **Breadth is the brand.** The range of project types (chat, games, tools, visualization) is the positioning — don't narrow it.
4. **Respect the scan.** Most visitors will not read everything. Structure for 30-second evaluation.
5. **Ship truth.** Only show real projects, real skills, real links. No fabricated content.
